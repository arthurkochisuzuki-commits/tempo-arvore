# Eco-Guardião: O Ciclo das Máscaras 🌿

Um jogo temático de ecologia sobre esquiva e máscaras sagradas. Defenda a natureza contra o Espírito da Corrupção!

## 🚀 Como Iniciar

1.  Certifique-se de ter o **Node.js** instalado.
2.  Abra a pasta no terminal ou use o comando abaixo.
3.  Execute o arquivo `run.bat` para iniciar o servidor de desenvolvimento.

## 🕹️ Controles

*   **Setas Esquerda/Direita** ou **A/D**: Mover o Guardião.
*   **Mouse**: Interagir com os menus.

## 🛠️ Tecnologias

*   Vite
*   JavaScript (Canvas 2D)
*   CSS Moderno
